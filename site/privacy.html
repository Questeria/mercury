Privacy Statement

Mercury is an end-to-end encrypted messenger. This statement describes the public website at mercury-messaging.com and the Windows installer download hosted there.

Personal Information Collected By The Website

The Mercury website does not have account registration, contact forms, payment forms, advertising cookies, or analytics cookies. Mercury does not intentionally collect names, email addresses, phone numbers, payment information, message contents, or app account identifiers through this website.

The website is hosted on Cloudflare Pages. When someone visits the site or downloads the installer, Cloudflare may process standard hosting and security log data such as IP address, browser or user-agent information, requested URL, timestamp, and related request metadata.

Why The Website Processes This Information

This information is used to operate the website, deliver the Windows installer and checksum, secure the site, diagnose availability or abuse issues, and maintain basic hosting records. Mercury does not sell website visitor information and does not use it for advertising.

Mercury App And Relay

The Mercury desktop app stores identity keys on the user's device. Message contents are end-to-end encrypted before they reach a relay. A relay may process routing metadata needed to deliver opaque ciphertext, such as account identifiers, timestamps, ciphertext sizes, and network connection metadata. The relay is not intended to receive plaintext message contents.

Data Sharing

Website hosting and security processing is provided by Cloudflare. The Windows installer is code-signed through Microsoft Azure Artifact Signing. Mercury does not sell personal information.

Retention

Mercury does not maintain a separate website visitor database. Hosting and security logs are retained according to the policies and settings of the hosting provider and are used only for the operational purposes described above.
